# Engineering thesis strategy

- Structure: engineering problem, design constraints, technical route, experiment/simulation, performance analysis, application boundary.
- High-risk review issues: weak feasibility evidence, missing parameter explanation, no failure analysis.
- Method requirements: design rationale, materials/equipment, procedure, indicators, validation.
- Evidence types: test data, simulation, prototype performance, standards.
- Innovation expression: focus on design improvement, process optimization, performance gain, or application validation.
- Avoid: broad scientific claims unsupported by engineering tests.

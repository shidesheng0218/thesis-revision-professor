# Computer science thesis strategy

- Structure: problem, related work, method/system, experiment, results, discussion, conclusion.
- High-risk review issues: no baseline, unclear metric, unreproducible experiment, contribution only engineering packaging.
- Method requirements: algorithm/system design, data, baselines, metrics, ablation or comparison when relevant.
- Evidence types: experiment tables, benchmark results, complexity analysis, system logs, user study.
- Innovation expression: specify algorithmic, system, dataset, evaluation, or application contribution.
- Avoid: claiming superiority without baseline or statistically meaningful comparison.

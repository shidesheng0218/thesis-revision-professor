# Cross-section consistency protocol

Run deterministic fact extraction first, then ask Codex to review the limited
candidate contradictions using the original paragraphs and evidence ledger.

The deterministic layer may flag exact conflicts in sample sizes, dates,
percentages, identifiers and citations. It must abstain when two expressions
could be semantically compatible. A semantic reviewer must return a locator,
confidence, counterevidence and an acceptance test for every escalation.

Never repair a contradiction by choosing the larger, newer or more frequent
value. The author must identify the authoritative source and confirm the
replacement.

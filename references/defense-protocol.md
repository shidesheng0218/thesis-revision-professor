# Blind-review and defense protocol

Defense questions are generated from review findings, unresolved claims and
cross-section risks. Each question must link to a paragraph locator, claim ID
or evidence ID.

An answer frame may summarize existing evidence and state a limitation. It
must not add an unreported experiment, sample, statistic, citation, legal
authority or contribution. When the source is insufficient, the answer frame
must say so explicitly and identify the material the author needs to prepare.
